# Автозапуск радио для Lampa

Плагин для [Lampa](https://github.com/yumata/lampa-source): добавляет в настройки раздел **«Автозапуск радио»**
и при старте приложения запускает выбранный объект. Сейчас поддерживаются каналы радио
[SomaFM](https://github.com/tsynik/tsynik.github.io/blob/master/lampa/soma.js) и Radio Record
(плагин `http://pl.bylampa.online/radio_record.js`), а также свой поток по любому адресу. Другие плагины могут
добавлять свои объекты через API.

Плагин состоит из одного файла `autostart-radio.js` (ES5, без сборки) и подключается по URL.

## Установка

1. В Lampa откройте **Настройки → Расширения → Добавить плагин** и укажите
   `https://etix-git.github.io/lampa-plugins/autostart-radio.js`.
2. Для автозапуска радио установите также нужный плагин радио: SomaFM (`https://tsynik.github.io/lampa/soma.js`)
   и/или Radio Record (`http://pl.bylampa.online/radio_record.js`).
3. Перезапустите Lampa.

В **Настройки → Расширения** плагин называется «Автозапуск радио» (на языке интерфейса), автор `@etix`.
Плагин сам записывает имя при первой загрузке, поэтому оно появляется при следующем открытии экрана.
Если у записи уже есть другое имя (например, его задал установщик), плагин его не меняет.

### webOS: ввод адреса из консоли

Набирать URL пультом неудобно. На ТВ с root (Homebrew Channel) адрес можно вставить командой по SSH:

1. В Lampa на ТВ откройте **Настройки → Расширения → Добавить плагин**, чтобы поле ввода было активно.
2. Выполните на ТВ:

   ```sh
   luna-send -n 1 luna://com.webos.service.ime/insertText '{"text":"https://etix-git.github.io/lampa-plugins/autostart-radio.js","replace":true}'
   ```

   Команда вставляет текст в активное поле ввода, `"replace":true` заменяет его прежнее содержимое.
   Ответ `{"returnValue": true}` означает, что текст вставлен.
3. Подтвердите ввод в Lampa и перезапустите приложение.

## Настройки

**Настройки → Автозапуск радио**

| Параметр | Значения |
|---|---|
| Автозапуск при старте | Нет (по умолчанию) / Немедленно / Через 3, 5, 10, 15, 30 сек после загрузки Lampa; время не действует, если отсчитывается простой, см. [ниже](#запуск-при-простое) |
| Что запускать | SomaFM / Radio Record / Свой поток (по умолчанию) / объекты других плагинов |
| Запускать при простое | Немедленно (по умолчанию), 30 сек, 1, 3, 5, 10, 20, 30, 60 мин, см. [ниже](#запуск-при-простое) |
| После просмотра видео | Ничего не делать (по умолчанию) / Запускать немедленно / Запускать при неактивности, см. [ниже](#продолжение-после-видео) |

Параметры объекта показываются только тогда, когда этот объект выбран в поле «Что запускать».
Чтобы ничего не запускать, выберите «Нет» в «Автозапуск при старте». Если раньше в «Что запускать» было выбрано
«Ничего», после обновления там стоит «Свой поток», а в «Автозапуск при старте» — «Нет».

До версии 1.9.0 «Автозапуск при старте» был переключателем, а время задавала отдельная настройка
«Задержка запуска». После обновления значение собирается из них: выключено → «Нет», без задержки →
«Немедленно», иначе «Через N сек».

### Запуск при простое

**Запускать при простое** задаёт, сколько времени пользователь не должен трогать Lampa, чтобы радио включилось.

- Отсчёт идёт только в режиме «Играть». В режиме «Пауза» отсчёта нет: иконка появляется через время из
  «Автозапуск при старте», как при простое «Немедленно».
- Отсчёт начинается сразу после загрузки Lampa, время из «Автозапуск при старте» к нему не добавляется
  (там достаточно выбрать любое значение, кроме «Нет»). Например, при простое
  1 мин без действий радио включится через минуту после старта, а если нажать кнопку на 50-й секунде — ещё
  через минуту после этого нажатия.
- Отсчёт начинается заново при нажатии кнопок пульта или клавиатуры, клике, движении мыши, касании и прокрутке.
- У своего потока на время отсчёта в шапке появляется иконка в остановленном виде, полоски паузы на ней мигают
  (см. [«Свой поток»](#свой-поток)). Нажатие на иконку сразу включает поток и отменяет отсчёт.
- Если за время ожидания радио включили или выключили вручную (иконкой своего потока, запуском канала SomaFM
  или Radio Record), отсчёт отменяется и больше не начинается.
- Пока открыт видеоплеер или Lampa свёрнута (внешний плеер), простой не считается: радио не включится поверх фильма.
  Отсчёт при этом не отменяется и продолжается после выхода из плеера.
- То же время используется для варианта «Запускать при неактивности» в настройке «После просмотра видео».
- Ожидание почти не нагружает устройство: обработчики событий только запоминают время последнего действия,
  проверку делает один таймер. После запуска обработчики снимаются, при «Немедленно» не ставятся совсем.

### Радио: SomaFM и Radio Record

Параметры одинаковые для обоих объектов:

- **Плагин …**: первая строка группы показывает, установлен ли нужный плагин радио: «установлен»,
  «выключен» (включите его в **Настройки → Расширения**) или «не установлен» (с адресом, который нужно
  добавить). Если при старте плагина нет или он выключен, автозапуск сразу показывает уведомление
  с тем же текстом и не ждёт плагин.
- **Канал**: «Последний прослушанный» или любой канал из списка радио. Список кешируется и обновляется
  при открытии раздела.
- «Последний прослушанный»: плагин запоминает каждый канал, включённый в плагине радио, в том числе
  переключение каналов на полноэкранном экране Radio Record.
- **Режим при старте**:
  - «Играть» (по умолчанию): канал сразу начинает играть;
  - «Пауза»: в шапке появляется иконка радио с обложкой канала, но звук не включается. Канал
    запускается нажатием на иконку, дальше она работает как обычная кнопка play/stop плагина радио.
    Отсчёт простоя в этом режиме не идёт, иконка появляется через время из «Автозапуск при старте».
- Канал играет в фоне. В шапке появляется мини-плеер, а полноэкранная информация о канале не
  открывается, даже если она включена в настройках радио. Стартовая страница не меняется.

SomaFM: каналы из `https://somafm.com/channels.json`, качество потока выбирается так же, как в самом
SomaFM, с учётом его настройки «AAC».

Radio Record: каналы из `https://www.radiorecord.ru/api/stations/`, поток выбирает сам плагин
(320 → 128 → HLS). Названия настроек в `radio_record.js` зашифрованы, поэтому на время запуска канала
все включённые настройки, которые плеер при этом читает, считаются выключенными. Так экран
информации не открывается. Сами настройки не меняются.

- Если при автозапуске всё же открывается полноэкранный экран канала, проверьте версию плагина в
  **Настройки → Расширения** (нужна 1.0.1 или новее; в консоли есть строка `AutostartRadio version …`).
  Если версия старая, значит, Lampa загрузила файл из кеша: добавьте к URL плагина `?v=2` и перезапустите
  приложение. Если экран открылся из-за другой сборки `soma.js`, плагин сам закрывает его и возвращает
  управление текущей странице.

### Свой поток

Свой адрес радио, для него не нужен сторонний плагин: играет встроенный мини-плеер автозапуска.

- **Название**: подпись у иконки радио в шапке, по умолчанию «Моё радио» (My radio, Моє радіо, Маё радыё —
  на языке интерфейса). Если очистить поле, вернётся название по умолчанию.
- **Адрес потока**: по умолчанию `https://choco.hostingradio.ru:10010/fm`. Подходят прямой поток mp3/aac,
  плейлист `.pls`/`.m3u` (берётся первый адрес из него) и HLS `.m3u8`, если его поддерживает устройство. Если
  очистить поле, вернётся адрес по умолчанию. Если адрес не начинается с `http://`/`https://`, при старте появится уведомление.
- **Режим при старте**: «Играть» или «Пауза», как у SomaFM и Radio Record. В режиме «Пауза» отсчёта простоя нет.
- **Громкость**: 2, 4, 6, 8 %, затем 10–100 % с шагом 10, по умолчанию 50 %. Действует при любом запуске, в том числе иконкой в шапке.
  Если поменять значение, пока поток играет, громкость меняется сразу.
- **Плавное нарастание громкости**: Выкл, 5, 10 (по умолчанию), 20, 30, 40, 50 или 60 сек. Громкость растёт от тишины
  до выбранной в «Громкость» при автозапуске в режиме «Играть» и при продолжении после видео. Отсчёт начинается,
  когда звук пошёл, поэтому буферизация потока его не съедает. Ручной запуск иконкой в шапке сразу играет на
  выбранной громкости, остановка посреди нарастания тоже её возвращает. Громкость и нарастание есть только у своего
  потока: SomaFM и Radio Record играют своими плеерами, и их громкость автозапуск не трогает.
- В шапке появляется иконка радио. При наведении видно название, нажатие запускает и останавливает поток.
  Если запустить SomaFM или Radio Record, свой поток останавливается, и наоборот. При запуске видео в Lampa
  радио тоже останавливается. Включится ли оно после выхода из плеера, задаёт настройка «После просмотра видео».
- Остановленный поток: иконка приглушена вместе со значком паузы — двумя вертикальными полосками в её правом
  нижнем углу, внутри рамки. Так выглядит и режим «Пауза», и остановка кнопкой, видео или ошибкой потока.
- Отсчёт простоя (перед автозапуском и перед продолжением после видео): те же полоски мигают — 4,5 сек видны,
  0,5 сек скрыты. Полоски есть только у своего потока, кнопки SomaFM и Radio Record не меняются.

### Продолжение после видео

Настройка **После просмотра видео** действует для всех трёх объектов, в том числе для радио, включённого вручную.

- «Ничего не делать» (по умолчанию): поведение как раньше. Свой поток при запуске видео останавливается,
  SomaFM и Radio Record плагин не трогает.
- «Запускать немедленно»: если радио играло, на время видео оно останавливается и через 1,5 с после выхода
  из плеера включается снова. При переключении серий радио не включается. После внешнего плеера радио
  включается, когда Lampa снова на экране. Если раньше было выбрано «Продолжить воспроизведение», после
  обновления здесь стоит этот вариант.
- «Запускать при неактивности»: то же самое, но после выхода из плеера радио ждёт время из
  [«Запускать при простое»](#запуск-при-простое). Каждое нажатие начинает отсчёт заново, новое видео
  отменяет ожидание. У своего потока во время ожидания мигают полоски паузы на иконке. Если там выбрано
  «Немедленно», вариант работает как «Запускать немедленно».
- Если радио остановили кнопкой до видео, после видео оно не включается. Если во время ожидания радио
  включили или выключили вручную, ожидание отменяется: радио само не включится ни сейчас, ни после
  следующего видео.

## API для других плагинов

```js
function addAutostartRadio() {
    Lampa.AutostartRadio.register({
        id: 'my_plugin',            // значение в «Что запускать»
        name: 'My plugin',          // подпись в списке и заголовок группы параметров

        // необязательно: свои параметры (формат Lampa.SettingsApi.addParam без component).
        // Они видны только когда выбран этот объект.
        settings: function (addParam) {
            addParam({
                param: { name: 'autostart_my_plugin_item', type: 'select', values: { a: 'A', b: 'B' }, default: 'a' },
                field: { name: 'Что открыть' }
            });
        },

        // необязательно: вызывается один раз после app:ready
        init: function () {},

        // необязательно: проверка перед запуском. Верните текст ошибки (например, «нужен плагин …»),
        // чтобы показать уведомление и не запускать run, или null, если всё в порядке
        check: function () {
            return window.my_plugin ? null : 'нужен плагин My plugin';
        },

        // выполнить автозапуск; fail(message) покажет уведомление
        run: function (done, fail) {
            var item = Lampa.Storage.field('autostart_my_plugin_item');
            // ... запуск ...
            done();
        },

        // необязательно: продолжение после видео (см. «Продолжение после видео»)
        active: function () { return true; },     // объект сейчас играет
        suspend: function () {},                  // остановить на время видео
        stop: function () {},                     // остановить, если продолжение выключено
        resume: function (done, fail) { done(); }, // запустить снова; fail(message) покажет уведомление

        // необязательно: true, если объект стартует на паузе (только иконка) — тогда отсчёта простоя нет
        paused: function () { return false; },
        // необязательно: показать (true) или убрать (false) отсчёт простоя на своей иконке
        countdown: function (on) {}
    });
}

if (window.Lampa && Lampa.AutostartRadio) addAutostartRadio();
else document.addEventListener('lampa_autostart_radio_ready', addAutostartRadio);
```

Плагины загружаются параллельно, поэтому порядок загрузки не важен. Если объект зарегистрируется позже
старта, автозапуск ждёт его до 30 секунд.

## Ограничения

- В десктопных браузерах политика autoplay может заблокировать звук без действия пользователя.
  На ТВ и в Android-приложении Lampa автозапуск обычно работает.
- Интеграция с SomaFM использует глобальный объект `window.somafm_player` из `soma.js`, с Radio Record —
  `window.radio_player` из `radio_record.js`. Если авторы изменят их API, провайдеры нужно будет обновить.
- Продолжение после видео для Radio Record предполагает, что `radio_player.destroy()` останавливает звук, как
  в SomaFM. Исходник `radio_record.js` обфусцирован, и проверить это по коду не удалось.
- Громкость и плавное нарастание своего потока меняют громкость аудиоэлемента (`audio.volume`). Там, где она
  только для чтения (например, iOS Safari), поток играет сразу на полной громкости.
- Если Lampa открыта по `https`, браузер не даст воспроизвести поток по `http` (mixed content). В Android-приложении
  и на ТВ Lampa обычно открыта по `http`, там это не мешает.
- Список каналов Radio Record загружается напрямую с `radiorecord.ru`. Этот API не отдаёт CORS-заголовки,
  поэтому в браузерной версии Lampa список может не загрузиться. В Android-приложении запросы идут
  нативно, и всё работает.
