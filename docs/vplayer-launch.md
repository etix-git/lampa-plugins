# Запуск в Vplayer

Плагин `vplayer-launch.js` (ES5, без сборки) добавляет на webOS третий способ воспроизведения — нативное
приложение **Vplayer** (`com.sostk.vplayer`, движок libVLC). Оно играет то, с чем не справляются встроенный
плеер Lampa и плеер WebOS: MKV с любыми дорожками, ASS-субтитры, DTS и т. п.

## Где появляется

- **Настройки → Плеер → Тип плеера** (для видео, IPTV и торрентов): кроме «Встроенный» и «WebOS» есть
  значение **Vplayer**. Выбранный тип запускает Vplayer вместо плеера Lampa.
- **Долгое нажатие на файл в торренте**: после «Запустить плеер - WebOS» есть пункт
  **«Запустить плеер - Vplayer»**. Он запускает Vplayer один раз, независимо от настроек.

Vplayer получает ссылку на файл (для торрентов — ссылку TorrServer с `&play`) и время, с которого продолжить
просмотр.

## Установка

1. Установите Vplayer на телевизор (Homebrew Channel, приложение `com.sostk.vplayer`).
2. **Настройки → Расширения → Добавить плагин**, адрес
   `https://etix-git.github.io/lampa-plugins/vplayer-launch.js`, затем перезапустите Lampa.

Если Vplayer не установлен, при запуске появится уведомление «Vplayer не установлен».

## Ограничения

- Работает только на webOS; на других платформах плагин ничего не делает.
- Vplayer получает один файл: плейлист серий из Lampa не передаётся, следующую серию запускайте из Lampa.
  Заголовок в Vplayer — имя из ссылки.
- Позиция просмотра в Vplayer не возвращается в Lampa (отметка «просмотрено» не обновляется), но запуск
  с сохранённого места работает.
- IPTV: открывается только текущий канал; переключать каналы нужно в Lampa.
- Ссылки YouTube по-прежнему открываются в Lampa.
- Если отключить плагин при выбранном «Vplayer», Lampa будет использовать встроенный плеер.
