# Сброс настроек субтитров

Плагин `subtitles-reset.js` (ES5, без сборки) — аналог `nb557.github.io/plugins/reset_subs.js`. Если вы меняли
настройки субтитров и запутались в них, этот пункт возвращает их «по умолчанию».

В меню настроек встроенного плеера (шестерёнка на панели плеера → **Субтитры**) сразу после
«Сместить время» появляется пункт **«Сбросить настройки»**. Сброс выполняется сразу, без подтверждения,
затем появляется уведомление «Настройки субтитров сброшены».

## Установка

**Настройки → Расширения → Добавить плагин**, адрес
`https://etix-git.github.io/lampa-plugins/subtitles-reset.js`, затем перезапустите Lampa.

## Что сбрасывается

| Где | Параметры |
|---|---|
| Меню плеера → Субтитры | размер, окантовка, подложка, сдвиг времени |
| Настройки → Плеер → Субтитры | включение при запуске, язык, источник субтитров торрента, оформление ASS, шрифты из торрента, читаемость диалогов ASS |
| webOS | параметры встроенных дорожек телевизора (`webos_subs_params`) |

Значения по умолчанию берутся из самой Lampa (`Lampa.Params.defaults`). Если сборка Lampa не знает
какой-то параметр (например, в старых версиях нет настроек ASS), он пропускается.
Размер, окантовка и подложка меняются на экране сразу.

Настройки плагина [«Субтитры: Plus»](subtitles-plus.md) не сбрасываются, у него есть свой пункт «Сбросить».

## Ограничения

- На webOS параметры встроенных дорожек Lampa держит в памяти, поэтому их вид изменится после перезапуска
  приложения.
- Если настройки синхронизируются через аккаунт CUB, сброс тоже синхронизируется.
